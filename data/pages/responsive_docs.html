Introduction to Prism UI

Prism UI is an accessible, themeable component library for React. Build products faster without sacrificing quality or inclusivity.

💡
You're reading docs for v3.2.0. If you're on v2, see the migration guide.

Installation

Install Prism UI using your preferred package manager:

npm install @prism-ui/react
# or
pnpm add @prism-ui/react

Then wrap your application with the PrismProvider:

import { PrismProvider } from '@prism-ui/react';

export default function App({ children }) {
  return (
    <PrismProvider>
      {children}
    </PrismProvider>
  );
}
✅
Prism UI is tree-shakeable. Only the components you import are included in your bundle.

Button component

The Button component is the building block of all interactive elements. It supports five visual variants and three sizes.

Props

PropTypeDefaultDescription
variantstring"primary"Visual style: primary, secondary, ghost, danger, link
sizestring"md"sm | md | lg
disabledbooleanfalseDisables interaction and dims the button
loadingbooleanfalseShows a spinner and prevents double submission
onClickfunction—Click event handler
⚠️
Always pair loading with a disabled state to prevent multiple submissions on async actions.

Responsive system

Prism UI ships with five breakpoints based on a mobile-first scale. You can override any breakpoint in the theme provider.

const theme = {
  breakpoints: {
    sm: '480px',   // Mobile portrait
    md: '768px',   // Tablet
    lg: '1024px',  // Small desktop
    xl: '1280px',  // Desktop
    '2xl': '1536px' // Wide screen
  }
};
